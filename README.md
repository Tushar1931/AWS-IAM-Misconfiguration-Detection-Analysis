# Entra-id-user-management
Cloud based Identity and Access Management lab built using Microsoft Entra ID. Demonstrates user provisioning, RBAC, MFA enforcement, conditional access policies, and security monitoring.

This project simulates a real-world Identity and Access Management (IAM) environment using Microsoft Entra ID (Azure Active Directory).

The lab demonstrates how organisations manage users, control access, and enforce security policies in a cloud environment.

## What this project covers
- User provisioning and identity lifecycle management
- Group-based access control
- Role-Based Access Control (RBAC)
- Multi-Factor Authentication (MFA)
- Conditional Access policies
- Application access management
- Sign-in monitoring and log analysis
